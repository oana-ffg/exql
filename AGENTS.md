# ExQL

When Oana asks for a feature change:

1. Implement it and add tests.
2. Get a review from Sol 6.1, or from Opus 5.5 if Sol implemented it. Fix the findings that make sense and discuss the rest with the reviewer until you agree. If you cannot agree, ask Oana.
3. Open a PR and check that CI passes. If it does, merge and publish a release (`scripts/release.ps1`, see README).
