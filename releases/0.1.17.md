# ExQL 0.1.17

- **See a table's structure.** A new **Structure** button beside **Data** lists every column of a table or view with its exact declared type, such as `nvarchar(50)`, `nvarchar(max)`, `decimal(18,2)` or `datetime2(7)`. Alias types also show the type they stand for, and SQL Server 2025 vectors show their dimensions. Next to each type come the column's extended properties: `MS_Description`, the description SSMS edits, plus a column for every other property name. Nullability, primary key, identity, default, computed definition and collation are listed too, and the table's own extended properties appear above the columns.
- **Exact sql_variant decimals.** Query results with a `sql_variant` value holding a decimal of more than 28 or 29 significant digits, such as `decimal(38,0)`, now show every digit. Previously such values could not be read.
