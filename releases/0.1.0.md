ExQL is a portable Windows x64 SQL Server and Azure SQL workspace with a data grid, SQL editor, saved queries, and saved connections backed by Windows Credential Manager.

- Adds automatic background downloads for stable releases, with a manual update check and an explicit restart button.
- Blocks update restarts while operations are running, cell edits are staged, workspace saves are pending or have failed, or dialogs are open.
- Preserves saved connections, queries, and scratch SQL when replacing application files.

Extract the complete portable ZIP into a writable folder and run its root ExQL.exe. Keep the updater and current folder together. No installer or administrator rights are required; WebView2 must be available.

This release is unsigned. Older standalone ExQL.exe builds need a one-time switch to the portable ZIP to receive future updates.
