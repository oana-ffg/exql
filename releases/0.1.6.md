# ExQL 0.1.6

- Link script folders instead of importing them. **SQL scripts > Add script folder** shows the `.sql` files currently on disk in that folder and its subfolders, such as Downloads or a project's scripts folder. ExQL only reads these files; it never copies, changes, or uploads them. Listings and open scripts refresh when you return to the window. Click a script to open its latest version, or use its Run button to open and run it in one click.
- Remove **Import SQL folder**. Queries imported with earlier versions remain in Saved queries.
- Right-click a saved connection to connect, edit, clone, or delete it. A clone copies the server, database, and options, picks a new color, and can keep the original's password or connection string in its own Credential Manager entry, or use a different login.
- **Copy all as text** copies every result set from the last run, including rows beyond the loaded page, plus any messages, as one labelled plain-text block for pasting into an AI chat or a note.
