# ExQL 0.1.12

- **Script timeouts are now yours to set.** The gear button in the top bar opens **Settings**, where you can change the default from 2 minutes. **Timeout** next to Run SQL changes it for one tab, including **No limit** or a custom number of minutes up to 24 hours, and lasts until you change it or close the app. The limit applies to each batch separated by `GO` and to each `GO n` repetition. Table loads and table exports keep their 120-second limit.
- **A timeout now explains itself.** The error says the batch timed out, after how long, and where to change the limit. Scripts with several batches also say which batch stopped, and results from finished batches stay visible.
- **Panes can be resized.** Drag the divider beside the sidebar or between the SQL editor and its results, or focus a divider and use the arrow keys, Home and End. Double-click a divider to reset it. Sizes are saved between restarts and shared by all workspaces.
- **The editor gets the whole pane until there is something to show.** The results area now appears once a run returns something, rather than sitting empty below a short editor. A tab without a connection keeps its connect button in a small bar below the editor.
