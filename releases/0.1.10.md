# ExQL 0.1.10

- **Tabs for saved connections now reconnect by themselves after a restart.** Previously the tabs and their SQL came back offline. A tab that cannot reconnect shows why, with **Reconnect** and **Use a different connection**. Tabs you disconnected stay offline, Microsoft Entra tabs wait for a click because sign-in opens a browser window, and unsaved connections stay offline because no credential is stored.
- **Fixed: Add connection could replace an offline tab**, leaving its SQL attached to a different database. It now always adds a tab, unless the only thing open is the empty starting tab.
- **Failed runs now keep what already finished.** Result sets, messages and affected rows from completed batches stay visible beside the error, and **Copy all as text** includes the error. Execution still stops at the first failed batch.
- **Closing a tab no longer asks about its SQL.** The text is saved as a dated `.sql` file in `%LOCALAPPDATA%/ExQL/temp_queries`, which appears under **SQL scripts**, unless it matches a saved query. If the save fails, the tab stays open and shows the error. ExQL never deletes these files. Closing a tab with staged cell edits still asks, because those are not SQL text.
- **Quitting right after typing no longer asks.** ExQL waits for the save instead. It still asks about staged cell edits, running operations and failed saves.
- **In the connection list, clicking a saved connection now connects.** The arrow and delete buttons are gone. Edit, Clone and Delete are in the right-click menu.
- Reloading the page no longer leaves old sessions behind that could block new connections.
