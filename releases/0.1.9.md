# ExQL 0.1.9

- **`GO` now works in the SQL editor**, in selections, and when running linked `.sql` scripts. `GO` on its own line separates batches and `GO n` repeats the preceding batch, so scripts can create procedures and views. All batches share one connection, so temporary tables, `SET` options, `USE` and open transactions carry over. A `GO` inside a string, quoted identifier or comment does not split a batch.
- **Running a script now stops at the first failed batch.** This differs from SSMS, which continues by default. The error names the batch and its location, and changes committed before the error remain. When a run fails, only the error is shown, not the results of earlier batches.
- The 30 result set and 256 MiB limits now apply to a whole run across all batches. The 120 second timeout applies to each batch execution.
- **Add script folder now opens the Windows folder picker** instead of asking you to type a path. You can still paste a path into the picker, including quoted paths and environment variables such as `%USERPROFILE%\Downloads`.
- Typing SQL is lighter: workspace saves are batched instead of writing every keystroke, result grids no longer re-render while you type, and linked script folders no longer refresh on window focus while their panel is hidden.
- Grids with many staged edits render with far fewer lookups, and late pages of large query results no longer reread the snapshot from its beginning.
