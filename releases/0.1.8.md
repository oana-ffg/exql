# ExQL 0.1.8

- Copying query results as SQL keeps `bit` columns as `bit`. The copied SELECT previously returned `1`/`0` as integers.
- Bit cells you have edited to `1` or `0` but not yet saved now copy correctly. SQL copy previously wrote `0` for a staged `1`, and JSON copy wrote the numbers `1`/`0` instead of `true`/`false`.
- Every pull request now runs automated end-to-end tests against real SQL Server 2019, 2022 and 2025, the Edge UI, and the packaged portable app, including a real update.
