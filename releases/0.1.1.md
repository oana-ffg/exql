ExQL 0.1.1 adds a new SQL-and-prohibition app icon and includes fixes made since 0.1.0.

- Adds the new icon to the Windows app, portable launcher, browser tab, and sidebar.
- Waits for saved workspace data to load before allowing workspace saves, protecting existing SQL and saved queries during slow startup.
- Preserves SQL date values through read/write round trips.
- Updates dependencies and runtimes with security patches.

Extract the complete portable ZIP into a writable folder and run its root `ExQL.exe`. Keep the updater and `current` folder together. Existing portable installations can receive this release through the app's update check.

This release is unsigned. No installer or administrator rights are required; Microsoft WebView2 must be available.
