# ExQL 0.1.16

- **Sort scripts by name or by newest.** A new button in **SQL scripts** switches the script folder listings between name order and newest created first, and ExQL remembers your choice. Name order is now natural, so `2.sql` comes before `10.sql`. When sorting by newest, the age beside each script shows when it was created, and each subfolder is placed by its newest script. Hovering a script shows both its created and modified times.
