# ExQL 0.1.14

- **See how long a query has been running.** While a query or any other operation is running, the status bar shows a live timer next to its name, as minutes and seconds or hours, minutes and seconds.
- **Long run times are easier to read.** When something finishes, the status bar shows seconds up to a minute and then the same clock format, so a long run shows `1:02:05` instead of `3725.12s`.
