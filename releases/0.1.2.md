# ExQL 0.1.2

- Keep multiple database connections open in separate workspace tabs. Switching preserves each workspace's SQL, results, table, filters, and staged cell edits. Queries can run in different workspaces at the same time.
- Import folders of `.sql` scripts from the Saved queries sidebar, preserving subfolders and filenames. UTF-8 and UTF-16 with a byte-order mark are supported. Imported scripts are saved copies; existing saved queries and source files are preserved.
- Restore SQL drafts for all open workspaces after restarting. Reconnect database sessions after reopening the app.
- Remove the misleading LOCAL badge, sidebar slogan, and decorative welcome copy. Connection cards and workspace tabs show the actual database server.
- Keep successful automatic update checks quiet. Manual check results disappear after five seconds, and update notices can be dismissed. Update and retry actions remain available in the toolbar.
- Include work running in inactive database workspaces in app-close and update-restart safeguards.
